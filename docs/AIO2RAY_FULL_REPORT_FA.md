# Aio2Ray Full Report (Persian)

## تاریخچه
اپلیکیشن Aio2Ray بر اساس کدهای v2rayNG و تغییرات v2box ساخته شده است. هدف اصلی، ارائه یک کلاینت پرکسی ۲ زبانه (فارسی/انگلیسی) با قابلیت ساخت خودکار APK از طریق گیت‌هاب است.

## ویژگی‌ها
- پشتیبانی از پروتکل‌های Vmess، Vless، Shadowsocks، Trojan و Hysteria
- رابط کاربری راست‌چین (فارسی) و چپ‌چین (انگلیسی)
- ساخت خودکار APK با GitHub Actions
- قابلیت به‌روزرسانی اشتراک و نمایش ترافیک

## مراحل ساخت APK
1. کدهای منبع را در گیت‌هاب آپلود کنید.
2. پروسه `build.yml` به صورت خودکار اجرا می‌شود.
3. فایل‌های APK در بخش Releases قرار می‌گیرند.
