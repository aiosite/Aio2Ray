# Aio2Ray 🌐

اپلیکیشن **Aio2Ray** یک کلاینت VPN/پرکسی چندپروتکلی (V2Ray/Xray) برای اندروید است که بر پایه کدهای `v2rayNG` و `v2box` ساخته شده است.

## ویژگی‌های اصلی
- **۲ زبانه:** پشتیبانی از زبان فارسی و انگلیسی (با تغییر خودکار بر اساس سیستم)
- **پروتکل‌های پشتیبانی شده:** Vmess, Vless, Shadowsocks, Trojan, Hysteria و غیره
- **ساخت خودکار APK:** تولید فایل APK از طریق گیت‌هاب (GitHub Actions)
- **نام پکیج:** `com.aio2ray.mobile`

## ساخت APK از گیت‌هاب
برای تولید نسخه APK:
1. کدهای منبع را در گیت‌هاب آپلود کنید.
2. پروسه **GitHub Actions** (`.github/workflows/build.yml`) به صورت خودکار APK را برای معماری‌های `arm64-v8a` و `armeabi-v7a` می‌سازد.
3. فایل‌های خروجی را از بخش **Releases** دانلود کنید.

## زبان‌ها
- **فارسی (FA):** راست‌چین (RTL)
- **انگلیسی (EN):** چپ‌چین (LTR)

## ساختار پوشه‌ها
- `app/src/main/res/values/` : زبان انگلیسی (پیش‌فرض)
- `app/src/main/res/values-fa/` : زبان فارسی
- `.github/workflows/` : تنظیمات ساخت APK در گیت‌هاب
- `docs/` : اسناد و مستندات
- `fastlane/` : تنظیمات انتشار و تست
